# Noma

[Открыть сайт](https://bakaebbi.github.io/Noma-coffee/) · [Исходный код](https://github.com/Bakaebbi/Noma-coffee)

Одностраничный сайт вымышленной кофейни в Екатеринбурге. Проект для портфолио. Адрес, часы работы и цены демонстрационные.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для запуска через локальный сервер выполните в папке проекта:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

Адрес сайта: http://localhost:8000. Остановка сервера: Ctrl+C.

## Файлы

- `index.html`: содержимое и навигация.
- `style.css`: палитра, типографика и адаптивная сетка.
- `images/coffee.webp`: фотография приготовления кофе.
- `images/favicon.svg`: иконка сайта.

Сайт использует HTML и CSS. JavaScript не требуется.

## Оформление

Кремовый фон, коричневый текст, светлый зелёный фон меню и тёмно-зелёный раздел «В гости». Заголовки: Cormorant Garamond, основной текст: Manrope. Шрифты загружаются через Google Fonts; при отсутствии сети используются системные шрифты.

Вёрстка рассчитана на экраны от 320 px. Предусмотрены клавиатурная навигация, ссылка перехода к содержимому и режим уменьшенного движения.

## Публикация

Разместите `index.html`, `style.css` и папку `images` на статическом хостинге. Сборка не нужна. Сохраните имена файлов и относительные пути.
